Kawaii Design System

⚡ Setup

Nur zwei Dateien – kein Build-Tool, kein Framework. Einfach im <head> einbinden.

HTML Einbindung
<!-- Im <head> --> <link rel="stylesheet" href="kawaii.css"> <!-- Vor </body> --> <script src="kawaii.js"></script>
Was du bekommst
✓ CSS Custom Properties für alle 30+ Design Tokens
✓ Alle Komponenten-Klassen (Buttons, Cards, Dialogs, …)
✓ Ripple-Effekte, Menus, Dialogs, Tabs — auto-initialisiert
✓ 40 kuratierte Farbpaletten — live shuffelbar via Kawaii.shuffle()
✓ Shuffle-FAB rechts unten (automatisch injiziert)

🧩 JS API

Das globale Kawaii-Objekt bietet alle Steuerfunktionen. Alles auto-initialisiert sich beim Seitenload.

API Referenz
MethodeBeschreibung
Kawaii.shuffle()Zufällige Palette aus 40 Kombinationen anwenden. Gibt die gewählten 3 Farben zurück.
Kawaii.setTheme(p, s, bg)Manuelle Palette setzen. 3 Hex-Farben: primary, secondary, surface.
Kawaii.getPalette()Array aller 40 PALETTE_COMBOS zurückgeben.
Kawaii.getActiveCombo()Aktuell aktive 3-Farb-Kombination abfragen.
Kawaii.openDialog(id)Dialog-Backdrop mit der gegebenen ID öffnen.
Kawaii.closeDialog(id)Dialog schließen.
Kawaii.showSnack(msg, opts)Snackbar anzeigen. Options: action, onAction, duration.
Kawaii.setProgress(el, val)Linear Progress Bar auf Wert 0–100 setzen.
Kawaii.makeSpinner(size, ind)Circular Spinner-Element erstellen und zurückgeben.
Kawaii.reinit()Alle Komponenten re-initialisieren (nach dynamischem DOM-Einfügen).
Kawaii.color.lighten(hex, t)Farbe aufhellen (t=0–1).
Kawaii.color.darken(hex, t)Farbe abdunkeln (t=0–1).
Kawaii.color.blend(h1, h2, t)Zwei Farben mischen (t=0→h1, t=1→h2).
Kawaii.color.contrastText(hex)#1a1a1a oder #ffffff – je nach Luminanz.
Data-Attribute Hooks (kein JS nötig)
AttributElementEffekt
data-dialog-open="id"Beliebiges ElementÖffnet Dialog mit der ID beim Klick
data-dialog-closeButton im DialogSchließt den übergeordneten Dialog
data-menu-toggle="id"Trigger-ButtonÖffnet/schließt Menu mit der ID
data-tabs-group="name".k-tabs und PanelsVerknüpft Tabs mit Panel-Elementen
data-tab-target="id".k-tab ButtonWelches Panel dieser Tab zeigt
data-kawaii-no-shuffleBeliebigUnterdrückt den Auto-Inject des Shuffle-FAB

🔀 Palette Shuffle

40 kuratierte Farbkombinationen aus 3 Gruppen (Warm, Cool, Rose). Der ⇄-Button rechts unten ist automatisch eingeblendet.

Live Palette Preview
Manuell aufrufen
// Zufällig shuffeln const combo = Kawaii.shuffle(); console.log(combo); // ['#CC5682', '#72AAA4', '#EEEBE5'] // Eigene Palette setzen Kawaii.setTheme('#CC5682', '#72AAA4', '#EEEBE5'); // Shuffle-FAB unterdrücken: <body data-kawaii-no-shuffle>
